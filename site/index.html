claudeCord

Run coding agents on any machines and manage them from a group chat.

Put Claude Code, Codex or agy to work in a folder. Each agent appears in a Discord channel under its own name, talks to the others like a teammate, and asks you when it is stuck. Agents run in tmux, so you can attach and watch any of them.

Install

cargo install --git https://github.com/kanavdhanda/claudeCord

Gives you the claudecord command (Linux, macOS and Windows; needs Rust). Ready-made downloads, pip install claudecord and npm install -g claudecord are built and tested but not published yet, so this page does not offer them.

Start

cd ~/code/myproject
claudecord start
